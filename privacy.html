Privacy

iLearnDeen free beta · last updated 18 November 2026

iLearnDeen is a free set of games for children. Children can play every game without an account, and the app does not ask for or collect anyone's name, email, age, photo or any other personal details.

What stays on your device

To remember progress, the app saves a few things in the browser's local storage on your own phone, tablet or computer:

  • the age group you chose (Little, Middle, Older or All ages)
  • the best score in each game
  • which games have been opened, so “How to play” only opens automatically the first time
  • simple settings, such as the unit filter, the team picked and the class joined

This information is not sent to us. You can delete it at any time by clearing this site's data in your browser settings.

You can also clear your scores with the Reset my progress button on the home screen.

Class sessions

If a teacher starts a class session and a child joins it with the class code, each game the child finishes sends the following to the class server (Supabase, hosted in Australia): the class code, the team picked, a random device number, the game and the score. No names or emails are ever sent. Anyone with the class code sees only team results, not individual scores. The teacher can delete the class scores at any time. Otherwise the session closes after 8 hours, nobody can see its scores after that, and they are deleted the next time the class server is used. Like the website host, the class server may keep short-term technical logs.

What other services see

  • Website hosting. Like any website, the hosting service receives standard technical information when the app loads, such as the IP address and browser type, and may keep short-term logs for security and reliability.
  • Feedback form (parents and teachers only). If you choose to send feedback, the form service processes what you type. Please don't include children's names or other sensitive personal information.
  • Usage counts. To learn which games are used, the app counts page visits, the app language, the age group chosen, and when a game is opened, played or finished, using GoatCounter. GoatCounter doesn't use cookies and doesn't store personal data that identifies anyone; it keeps totals such as browser type, screen size and approximate country.

The app has no advertising, no in-app purchases, no chat and no tracking cookies.

Changes

If a future version changes what information is collected, this page will be updated before that version goes live, and you'll be told what is collected and why.
